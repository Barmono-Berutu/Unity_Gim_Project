# 🎮 Unity Gim Project

**Unity_Gim_Project** adalah sebuah game endless runner yang saya buat menggunakan Unity, terinspirasi dari game populer seperti **Subway Surfers**. Di dalam game ini, pemain dapat berlari, melompat, sliding, dan mengumpulkan koin dengan efek suara yang menyenangkan dan visual yang imersif.

---

## 🚀 Fitur Utama

- 🎲 **Gameplay Sederhana dan Seru**  
  Start menu yang intuitif, kontrol karakter mudah dipahami.
  
- 🏃‍♂️ **Karakter Interaktif**  
  Bisa berlari, lompat, dan sliding untuk menghindari rintangan.

- 💰 **Koleksi Koin**  
  Pemain dapat mengumpulkan koin selama permainan berlangsung.

- 🔊 **Audio Dinamis**  
  Efek suara saat bergerak, melompat, dan mengumpulkan item.

- 🏙️ **Asset Visual Berkualitas**  
  Menggunakan asset dari Unity Store seperti:
  - Abandoned World  
  - Building Apartment  
  - Casual Game Sounds U6  
  - City Props Bundle  
  - Classic Footstep SFX  
  - Collectables Sound Pack  
  - Gold Coin  
  - UrbanBuilding  
  - dan lainnya
